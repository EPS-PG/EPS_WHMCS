EPS -WHMCS

Prerequisites
--------------
WHMCS V8.0 or later
cURL php extension.



How to install the WHMCS module?
----------------------------------
1. Copy the modules folder to your base whmcs folder. 
Or directory modules/gateways upload here eps.php and callback folder and file.

2.Login to the WHMCS Administrator.
3.Go to Addons ->Apps & Integrations->payments->Additional apps
4.Select Eps and Click Active
5.Enter the following details:
	Display Name
	Payment Button Label
	Username
	Password
	Hash key
	Merchent ID
	Store ID
	Enable Sandbox / Testmode?
	and Save changes.
Now ready to use.
