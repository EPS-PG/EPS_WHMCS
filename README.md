# EPS WHMCS

Official WHMCS payment gateway module for **EPS (Easy Payment System)**.

## Features
- Sandbox & Live mode support  
- Secure payment processing  
- Easy WHMCS integration  

## Requirements
- WHMCS v8.0+
- PHP cURL extension enabled

## Installation
1. Copy the `modules` folder into your WHMCS root directory  
   *(or upload `eps.php` and the `callback` folder to `modules/gateways`)*  
2. Login to WHMCS Admin Panel  
3. Go to **Apps & Integrations → Payments → Additional Apps**  
4. Select **EPSPG** and click **Activate**  
5. Configure the following settings and save:
   - Display Name  
   - Payment Button Label  
   - Username  
   - Password  
   - Hash Key  
   - Merchant ID  
   - Store ID  
   - Sandbox / Test Mode
